# AoE jt 0.2.0

这是 jt 维护的 Agent of Empires 分支 0.2.0 二进制发行版本, 包含自 0.1.0 以来的主要更新:

- 支持 Antigravity CLI (`agy`) 原生启动、SessionStart conversation UUID 采集、`r`/`R` 精确恢复以及 `c`/`C` 清空上下文并恢复原 xats 运行身份.
- 集成 `xats-agy` PTY 启动器与本机 `aoe __antigravity-mcp` 桥, 支持延迟注册、Named 自动恢复、8 项完整 xats 通信工具透传、瞬态交接重试与双向免提醒 auto poke.
- 改进 Antigravity 原地重启为两阶段原子替换, 优雅等待旧 `agy` 与启动器退出, 避免 `Conversation already open` 与 `agent_id_collision`.
- 持久化 Codex 会话恢复来源并复用 tmux 长连接监视, 显著降低 macOS 短命子进程创建频率; 修复恢复校验中 `pane_pid=0` 边界.
- 支持 OpenCode 跨 runtime 交接、删除 session 前尽力释放 xats pane 身份 (含 dead pane 保护), 以及 TUI 首页鼠标滚轮滚动.

通过自有 Homebrew tap 安装或升级:

```sh
brew tap jtianling/tap
brew install jtianling/tap/aoe
# 已安装时升级:
brew update && brew upgrade jtianling/tap/aoe
aoe --version
```

提供 macOS arm64、x86_64 和 Linux arm64、x86_64 二进制及 SHA256SUMS.
macOS 需要 13 或更新版本, Linux 需要 glibc 2.35 或更新版本.
tmux 为必需依赖, Homebrew 会自动安装.

这是自有版本号体系, 与上游版本号不可直接比较.
本分支关闭上游自动更新检查, 后续使用 `brew update` 和
`brew upgrade jtianling/tap/aoe` 更新.

如果本机已有 `~/.cargo/bin/aoe`, 它可能在 PATH 中优先于 Homebrew 版本.
可通过 `command -v aoe` 核对, 或使用 `"$(brew --prefix)/bin/aoe"` 明确运行.
