# AoE jt 0.1.0

这是 jt 维护的 Agent of Empires 分支首次独立二进制发行, 包含截至本版本提交的自有修改.

- 提供受 owner 和 xats fence 保护的 session、pane 管理 CLI.
- managed Codex 使用逐 pane 独立 app-server, 支持单独指定模型、推理强度和 YOLO 模式.
- 补齐 Codex 与 Claude 的多 pane 恢复、显式 Codex 绑定修复和原生会话命名.
- 已有 linked worktree 自动补齐 agent 配置和 skills, 保留已有文件及链接.
- 修复发送链路、重命名后的状态竞态和标题编辑延迟.

通过自有 Homebrew tap 安装:

```sh
brew install jtianling/tap/aoe
aoe --version
```

提供 macOS arm64、x86_64 和 Linux arm64、x86_64 二进制及 SHA256SUMS.
macOS 需要 13 或更新版本, Linux 需要 glibc 2.35 或更新版本.
tmux 为必需依赖, Homebrew 会自动安装.

这是自有版本号体系, 与上游版本号不可直接比较.
本分支关闭上游自动更新检查, 后续使用 `brew update` 和
`brew upgrade jtianling/tap/aoe` 更新.

与此前本地构建版本兼容性边界一致: 旧 AoE TUI 不应与新版 managed CLI
混合执行生命周期操作, 应正常退出并重新打开 TUI.  退出 TUI 会保留 agent session.
managed Codex、Claude 恢复及状态修复的隔离验收记录保存在 discuss/.
发布构建额外验证四个平台的版本输出及 CLI 入口, 不代表在每个平台重跑完整 agent 验收.

如果本机已有 `~/.cargo/bin/aoe`, 它可能在 PATH 中优先于 Homebrew 版本.
可通过 `command -v aoe` 核对, 或使用 `"$(brew --prefix)/bin/aoe"` 明确运行.
